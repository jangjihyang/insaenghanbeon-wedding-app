# v10 업데이트 안내 — 공개 정보공유 게시판 + 실제 지도 + 후보 확대

## 이번 업데이트

1. **공개 웹 기반 후보 확대**
   - 서울·경기·인천 장소 후보를 총 **255곳**으로 확대했습니다.
   - 기존 186곳 + 공개 목록·플랫폼·지도 검색 기반 추가 후보 69곳입니다.
   - 모든 후보에 출처 상태를 표시하며, 후보 목록은 현재 운영·예약 가능을 보증하지 않습니다.

2. **로그인 없는 정보공유 게시판**
   - 사이트 메뉴의 **정보공유**에서 회원가입 없이 장소 제보, 방문 후기, 질문, 정보 공유 글을 작성할 수 있습니다.
   - 공개 글은 개인정보·사진·타인 글 복사·광고 링크 위험이 있으므로 운영자가 주기적으로 확인해야 합니다.

3. **실제 지도 표시**
   - 카카오 지도 API 키가 없어도 메인 화면에 **OpenStreetMap 실제 지도**가 표시됩니다.
   - 장소를 누르면 공개 주소 또는 장소명으로 위치를 찾아 표시합니다.
   - 주소가 불명확한 후보는 지역 중심이 표시될 수 있으므로 외부 지도 링크에서 재확인해야 합니다.

## 반드시 먼저 할 일 — Supabase 공개 게시판 설정

1. Supabase Dashboard를 엽니다.
2. 왼쪽에서 **SQL Editor**를 누릅니다.
3. `supabase/COMMUNITY_BOARD_SETUP.sql` 파일을 엽니다.
4. 안의 내용을 전부 복사해 Supabase SQL Editor에 붙여넣습니다.
5. **Run**을 누릅니다.

이 SQL을 실행해야 로그인하지 않은 방문자가 `/community`에 글을 등록하고 다른 사람의 글을 볼 수 있습니다.

## GitHub Desktop 업데이트 순서

1. 이 ZIP을 내려받아 압축을 풉니다.
2. GitHub Desktop에서 현재 저장소를 연 뒤 **Show in Explorer**를 누릅니다.
3. 압축을 푼 폴더의 파일·폴더 전체를 프로젝트 폴더에 복사합니다.
4. 파일 교체 창이 나오면 **대상에서 파일 바꾸기**를 선택합니다.
5. `.git` 폴더는 절대 삭제하지 않습니다.
6. GitHub Desktop Summary에 아래를 입력합니다.

```text
공개 정보공유 게시판과 실제 지도 기능 업데이트
```

7. **Commit to main** → **Push origin**을 누릅니다.
8. Vercel Deployments 화면에서 최신 배포가 **Ready**가 되면 완료입니다.

## 운영 시 꼭 지킬 점

- 플랫폼 확인·추가 확인 필요 장소를 현재 운영 중인 장소처럼 단정하지 않습니다.
- 외부 블로그·SNS·플랫폼 사진과 후기 원문을 다운로드하거나 재게시하지 않습니다.
- 공개 게시판에 개인정보, 예약번호, 타인 사진, 명예훼손성 문구, 반복 광고·의심 링크가 올라오면 Supabase의 `community_posts` 테이블에서 해당 글 `status`를 `hidden`으로 바꾸세요.
- 상세 운영 기준은 `COMMUNITY_BOARD_OPERATION.md`와 `LARGE_VENUE_INVENTORY_GUIDE.md`를 참고하세요.
