# 공개 후기·소셜 리서치 반영 안내

- **확인일:** 2026-10-12
- **대상:** 서울·경기·인천 실제 웨딩홀 8곳
- **반영 방식:** 개인 후기 원문을 복사하지 않고, 로그인 없이 볼 수 있는 공개 블로그·리뷰 플랫폼·공개 SNS·촬영자 포트폴리오의 취지를 중립적으로 재서술했습니다.

## 안전한 데이터 표시 원칙

1. 모든 요약에는 출처 링크, 출처 유형, 확인일, 신뢰도를 제공합니다.
2. Google 지도 리뷰는 이번 조사에서 검증 가능한 공개 리뷰 URL을 확보하지 못하여 수집·인용하지 않았습니다.
3. 가입/로그인이 필요한 카페 글은 본문을 수집하거나 인용하지 않았습니다.
4. 후기 사진·영상은 블로그, Instagram, Threads, 리뷰 플랫폼에서 내려받거나 재게시하지 않았습니다. 원문 링크로만 연결합니다.
5. 가격·별점·수용 인원처럼 변동되거나 교차 검증이 어려운 정보는 게시하지 않았습니다.
6. 공식 SNS·촬영자 포트폴리오는 실제 이용자 후기와 구분해서 표기합니다.

## 운영 전 확인할 점

- 외부 링크는 게시물이 비공개 전환·삭제될 수 있으므로 정기 점검이 필요합니다.
- 후기 요약은 개인 경험을 일반화하지 않도록 "공개 후기에서는", "일부 방문자는" 같은 표현을 유지합니다.
- 원문 이미지 사용이 필요하면 반드시 작성자 및 웨딩홀 권리자로부터 별도 사용 허가를 받으세요.
